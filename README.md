# ケミカラ！ 〜無機化学 色マスター〜 🧪🎨

無機化学で覚える必要のある「色」を、**楽しいアクションゲーム**で完全マスターできるブラウザゲームです。

## 🎮 遊び方

1. **ゲームスタート**を押すと、画面上部に問題（物質・反応）が表示されます
2. 画面内を漂う**色のオーブ**の中から、正しい色をタップ／クリック！
3. 速く答えるほど**スピードボーナス**、連続正解で**コンボボーナス**
4. **8コンボ**でフィーバータイム突入！スコア2倍＆紙吹雪 🎉
5. ライフは3つ。間違えたり時間切れになると減ります
6. リザルト画面では**間違えた問題の復習リスト**を表示

## 📚 収録している色（抜け漏れなし！）

| カテゴリ | 内容 |
|---|---|
| 🔥 炎色反応 | Li赤・Na黄・K赤紫・Cu青緑・Ca橙赤・Sr紅・Ba黄緑（全7種） |
| 💧 イオンの色 | Cu²⁺, Fe²⁺, Fe³⁺, Ni²⁺, Cr³⁺, Mn²⁺, Co²⁺, MnO₄⁻, CrO₄²⁻, Cr₂O₇²⁻, 錯イオンなど |
| 🧪 沈殿の色 | ハロゲン化銀、硫化物（CuS, ZnS白!, CdS黄, MnS淡赤など）、水酸化物、クロム酸塩、硫酸塩・炭酸塩など30種以上 |
| 🔬 検出・呈色反応 | 紺青／ターンブル青、KSCN血赤、ヨウ素デンプン、フェーリング、銀鏡、ビウレット、キサントプロテイン、ニンヒドリン、塩化コバルト紙など |
| 💨 気体の色 | Cl₂黄緑、F₂淡黄、NO₂赤褐、NO無色、O₃淡青、Br₂/I₂蒸気など |
| 💎 単体・化合物(固体) | Br₂, I₂, S, 黄リン/赤リン, Cu, Au, 各種酸化物（CuO, Cu₂O, Fe₂O₃, Fe₃O₄, MnO₂…）、CuSO₄·5H₂O など |
| 🌡️ 指示薬 | フェノールフタレイン、BTB、メチルオレンジ、リトマス |

**合計 約100項目** を収録。タイトル画面でカテゴリを絞って出題できます。

## 📖 図鑑モード

全項目を色スウォッチ付きで一覧表示。ゲーム前の予習・テスト前の総復習に。
覚え方（ゴロ・注意点）のメモも付いています。

## ✨ ドーパミン設計

- 正解時のパーティクル爆発 & コンボで音程が上がる効果音
- コンボ表示・スピードボーナス・フィーバータイム（スコア2倍）
- ミス時は正解オーブが光り、解説メモが表示されて記憶に定着
- ハイスコア記録（localStorage）& NEW RECORD 演出

## 🚀 起動方法

静的サイトなのでそのまま開けます:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## 🛠️ 技術構成

- Vanilla JS + Canvas 2D（依存ライブラリなし）
- Web Audio API によるシンセ効果音（音声ファイル不要）
- レスポンシブ対応（スマホでもプレイ可能）

| ファイル | 内容 |
|---|---|
| `index.html` | 画面構造 |
| `style.css` | スタイル・アニメーション |
| `data.js` | 無機化学の色データベース（約100項目） |
| `game.js` | ゲームロジック・描画・効果音 |
