# ケミカラ！ 〜無機化学 完全マスター〜 🧪🎮

無機化学の「色」と「知識」を、エフェクト全開のアクションゲームで完全マスターできるブラウザゲーム。

## 🎮 遊び方

- **色問題** → 画面を漂う色オーブから正解をタップ！
- **知識問題** → 飛び出してくる4択から正解を撃ち抜け！
- 速答で **PERFECT / GREAT / GOOD** 判定 → PERFECTでボーナス＆ゲージ大幅UP
- **フィーバーゲージ**を貯めるとフィーバータイム（スコア2倍・紙吹雪の嵐）
- **5問正解ごとにLEVEL UP** → スコア倍率が×1.5, ×2.0…と青天井
- リザルトで **S/A/B/C/D ランク判定** ＆ スコアカウントアップ演出
- 間違えた問題は正解ハイライト＋解説メモ→リザルトで復習リスト化

## ✨ ドーパミン設計

- PERFECT判定の黄金グラデ演出＋専用ファンファーレ
- コンボで音程が上がる効果音・3コンボごとに画面中央コンボスプラッシュ
- 正解時の衝撃波＋パーティクル爆発＋画面フラッシュ
- レベルアップバナー＆倍率上昇（成長実感）
- フィーバーゲージ（貯める快感）→フィーバー中は画面が虹色に脈動
- リザルトのスコアカウントアップ＆ランク演出（Sランクで専用ファンファーレ）

## 📖 図鑑モード

全198項目を色スウォッチ・正解・ゴロ/解説付きで一覧表示。テスト前の総復習に。

## 🚀 起動方法

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## 🛠️ 技術構成

Vanilla JS + Canvas 2D + Web Audio API（依存ゼロ・音声ファイル不要）。スマホ対応。

| ファイル | 内容 |
|---|---|
| `index.html` | 画面構造 |
| `style.css` | スタイル・アニメーション |
| `data.js` | 色DB(101) + 知識クイズDB(97) |
| `game.js` | ゲームロジック・描画・効果音 |
